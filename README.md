# Sales Analysis with Python

## Project Overview
Analysis of sales data to identify product and regional performance.

## Tools
- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab

## Analysis
- Product sales and profit
- Regional sales and profit
- Profit margin
- Profit per unit
- Product-region performance
- Performance classification

## Key Findings
- West generated the highest overall sales and profit.
- Monitor performed particularly strongly in the West.
- Camera performed strongly in the South.
- Tablet showed relatively weak performance across regions.
- Printer performed particularly poorly in the North.

## Business Recommendations
- Protect strong product-region combinations.
- Investigate high-volume, low-margin products.
- Review consistently weak products.
- Investigate regional underperformance.
